# 思路和正确性

代码对吃香蕉的速度进行二分。速度为 `mid` 时，一堆 `item` 根香蕉需要 `(item - 1) // mid + 1` 小时，即向上取整。逐堆累加得到 `temHours`，一旦超过 `h`，即可判定当前速度不可行并提前结束检查。

速度越大，总耗时不会增加，因此可行性具有单调性。`left = 0` 作为不可行边界，`right` 初始化为最大堆大小；题目保证 `h` 不小于堆数，因此初始 `right` 一定可行。循环中 `mid` 始终为正数。

每轮判断后，若当前速度可行，则令 `right = mid`；否则令 `left = mid`，始终保持左端不可行、右端可行。两个端点相邻时，`right` 就是最小可行速度。

# 复杂度

设香蕉堆数为 `n`，最大堆大小为 `M`。

- **时间复杂度：** `O(n log(M + 1))`。寻找最大堆需要一次扫描，每轮二分最多检查全部香蕉堆。
- **辅助空间复杂度：** `O(1)`。仅使用固定数量的变量和固定长度列表，`nums` 直接引用原数组。
